# Вимога: додавання автомобіля Audi TT у Garage в гостьовому режимі

## Початковий стан

- Користувач відкрив QAuto за адресою https://qauto.forstudy.space/.
- Користувач авторизувався через `Guest log in`.
- Відкрито розділ `Garage`.

## Сценарій

1. Натиснути кнопку `Add car`.
2. У полі Brand обрати `Audi`.
3. У полі Model обрати `TT`.
4. У полі Mileage ввести `12000`.
5. Підтвердити додавання автомобіля кнопкою `Add`.

## Очікуваний результат

- Автомобіль успішно додається до Garage.
- У списку автомобілів Garage відображається автомобіль `Audi TT`.
- Для доданого автомобіля відображається пробіг `12000` (якщо він передбачений поточним UI).

## Межі

- Тест виконується в гостьовому режимі через `Guest log in`.
- Перевіряється додавання автомобіля через UI, без використання API.
- Тестові дані: Brand — `Audi`, Model — `TT`, Mileage — `12000`.
- Тест має використовувати локатори, підтверджені за поточним UI.
- Не використовувати fixed waits.
- Не змінювати `playwright.config.ts`, dependencies або product code.
- Якщо кнопка, поля або очікуваний результат відрізняються від опису чи автомобіль не вдається додати, зафіксувати фактичний blocker замість вигаданого успішного результату.
